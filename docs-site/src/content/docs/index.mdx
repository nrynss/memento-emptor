Memento Emptor is middleware: a memory layer for shopping agents that a merchant runs beside its PayPal app, not an agent. Your agent
plugs in over MCP: evidence arrives from the payment side without the agent
doing anything, the agent asks what applies before it recommends, and it reports
what the shopper says. The layer never moves money.

The two levels of memory are the product. It keeps what this shopper's own
evidence earned, and it pools classified outcomes across shoppers so a product
can run off-size before any one shopper has a history with it. A belief at
either level has to be earned from a reason that matches the evidence, and the
shopper stays in charge of every decision.

Second Fitting Helper. It borrows every size answer from the Memento
layer — asking first on each turn and obeying the winning rung — and it
keeps none itself. Corrections are filed to the layer the moment they
are spoken. It advises and seeks approval but holds no ordering tool,
so it cannot move money.
